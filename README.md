# Озёрск Рабочий

Лёгкая пародийная газета на FastAPI + SQLite. Никакого WordPress, никаких плагинов: один процесс,
одна база в файле, минимум зависимостей.

## Возможности

- Главная страница со свежими новостями
- Категории / тематики и поиск (полнотекстовый, через SQLite FTS5)
- Кабинет журналиста с публикацией / редактированием / удалением
- Кабинет редактора с управлением аккаунтами журналистов
- Загрузка обложки и картинок в текст напрямую (или прямой ссылкой)
- BB-коды и обычный HTML в теле новости (с очисткой от опасных тегов)
- Минималистичный дизайн в красно-чёрной советско-современной эстетике

## Быстрый старт

```bash
# 1. Установить зависимости
uv sync          # или: pip install -e .

# 2. Запустить сервер
uvicorn app.main:app --reload --port 8000

# 3. Открыть
#    http://localhost:8000          — газета
#    http://localhost:8000/admin    — редакция
```

При первом запуске создаётся аккаунт `admin` / `admin`. Поменяйте пароль через
кабинет редактора (`/admin/users`) или задайте через переменные окружения
`OZERSK_ADMIN_USER` и `OZERSK_ADMIN_PASSWORD` до первого старта.

## Создать журналиста из консоли

```bash
python scripts/create_user.py ivanov "Иван Иванов" qwerty
python scripts/create_user.py shef "Главред" hunter2 --admin
```

## Загрузить демо-контент

```bash
python scripts/seed_demo.py
```

## Конфигурация

Переменные окружения:

- `OZERSK_DB` — путь к файлу SQLite (по умолчанию `ozersk.db` в рабочей директории)
- `OZERSK_SECRET` — секрет для подписи cookie-сессий (на проде задать обязательно)
- `OZERSK_ADMIN_USER` / `OZERSK_ADMIN_PASSWORD` — креды стартового админа

## Деплой

Это обычное FastAPI-приложение. Подойдёт что угодно: `uvicorn`, `gunicorn`,
docker, fly.io, railway. Для долгоживущей базы подключите volume к `ozersk.db`
и каталогу `app/static/uploads/`.

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
